# ANIMA 5.6 · recovered and completed first broader milestone

## Implemented

- A pinned-block Rehearsal service executes supported master-NFT account intents on a disposable fork. Its source RPC proxy permits reads only. Reports measure balances, allowances, locks and account authority, and bind to exact transaction terms before wallet review.
- The instrument workshop snapshots selected public TimeVault schedules, deterministically compiles a release calendar, supports a fixed provider/evaluator/budget/deadline commission, validates the delivered bytes, and acquires accepted output as a frozen cartridge NFT in the master NFT account.
- Existing ownership checks, transfer invalidation and isolated cartridge execution remain. Acquisition grants no spending permission.
- The original optical object, mathematical interior, free gestures, privacy worker, encrypted state, fail-closed private execution, and v4 lifecycle are retained.

## Resumption repair

The prior turn had completed the local 5.6 implementation but stopped during its GitHub transfer. Its completed log reported 354 passing project tests and a successful local deployment/archive roundtrip. This continuation recovered the actual working tree, reviewed the new paths, and completed fresh validation.

A second rehearsal previously could leave an old signing review visible while its newly prepared transaction remained in the shared wallet. If the service failed, the mismatched transaction could still be signed without the requested rehearsal. The desk now clears the old review immediately, withholds the plan during rehearsal, and makes it signable only after successful binding. Failure, reversion or changed terms leave no signable replacement. A stale earlier operation cannot discard a newer review.

Nine new regression cases cover pending state, invalid service configuration, failed service execution, reverted or mismatched reports, overlapping operations, successful binding and ordinary explicit simulation/review. The focused desk/server/fork/live-protocol run passed 15 tests before the full gate.

## Remaining boundaries

This is the first broader implementation milestone. The hosted interface does not host the local fork service, deploy public blockchain contracts, or activate a broadcaster. Rehearsal requires an explicitly configured local service; the workshop requires compatible deployed contracts and a connected minted NFT.

The separately downloaded 15 MB privacy worker remains included in the source distribution and verified by its runtime SHA-256 pin. The immutable HTML archive includes the worker's pin, rather than the entire SDK/prover. Public-chain activation and funded shielded validation remain outstanding. Existing immutable minted editions do not change with this source release.

ERC-8183 interoperability, x402 service purchases, open provider discovery, arbitrary generated cartridges, and proof-backed rehearsal are later work. See [BROADER-ANIMA.md](BROADER-ANIMA.md) and [CONTINUATION.md](CONTINUATION.md) for setup, approved decisions and the next steps.
