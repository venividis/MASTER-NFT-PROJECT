# Anima Genesis 5.7

The interior now follows input with time-based camera smoothing. Entry advances its camera and optical blend together; a Functions menu stays within reach. Opening an instrument preserves the exploration position and provides Return inside. Swap, Vault, Memory, Commons and vesting routes open their transaction desks. Atlas keeps local economic rehearsals explicitly labelled.

The render budget adapts both resolution and volume samples to sustained frame timing, lowers work during navigation and recovers gradually while stationary. The authored blue radiance and interior medium equations are unchanged. Native GLES checks prove unchanged exterior pixels; they do not certify performance on every browser or phone.

The new wallet image is generated by GenesisSVG from the onchain snapshot. It retains luminous orbital rings around a blue body, carries ANIMA GENESIS branding and shows seed-derived detail and current generation, evolution and action counts. Animation is decorative: the complete still image remains when a wallet disables SVG animation.

Minted identity remains authoritative after wallet disconnection and local state changes. Connecting requires the edition's exact home chain, collection and token. A sealed GenesisManifest binds deployed market, vault, memory, world, cartridge and vesting contracts to the collection. The entry cannot be overwritten after publication.

The core application remains in immutable OnchainApp chunks. The privacy worker is now gzip-compressed into seven additional immutable shards, with at most 32 chunks per shard, with a ShardedResource directory bound into the NFT metadata. Recovery is lazy, reads one pinned block with bounded concurrency, validates every shard and the complete compressed and expanded SHA-256, bounds decompression and supports cancellation. Failure cannot silently fall back to an HTTPS worker. An owner may explicitly choose a mirror checked against the same pinned bytes.

## Remaining boundary

This release does **not** make the entire privacy stack autonomous onchain. RAILGUN circuit proving files still come from external sources. RPC, proof-of-innocence services, synchronization, broadcasters and local computation also remain network or browser requirements. Secrets and private notes stay local and must not be published onchain. A private RAILGUN wallet is separately controlled by its secret; NFT transfer does not transfer that secret.

Public-chain deployment has not been performed. The validation mint is on ephemeral chain 31337. Existing immutable collections retain their original renderer; these renderer and resource changes apply to a new deployment. Economic rehearsals are not live transactions, and keeper/provider actions require their corresponding running services.

## Reproduce

Run `npm ci`, then `npm run validate:genesis`. The validation regenerates the metadata loader, compiles contracts, builds the app, runs all tests, checks the complete core archive and deploys a local NFT. The local fixture also rebuilds and deploys the pinned worker archive, recovers all worker bytes, verifies the sealed module directory and emits a pristine mint thumbnail before seeded market actions. The generated worker shards are reproducible and are omitted from git; the reviewed worker source is tracked.

Run `python test/genesis/blue_projection.py` for the unchanged exterior pixel checks. The release's local mint and resource evidence is in `reports/confluence/local-deployment.json`; the source image is `docs/genesis/mint-thumbnail.svg`.
