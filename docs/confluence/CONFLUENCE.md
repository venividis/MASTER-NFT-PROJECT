All original substantive source remains available in the project or `integrations/`. Keeping donor code is not a claim that every donor module is integrated. Each repository’s default branch and meaningful branch differences were mapped. GitHub manifests record exact commits, source paths, hashes and URLs. Third-party dependency files retain their licenses; no unified license claim overrides those licenses.

## Product choices

The central body is the navigation system. Accessible textual controls expose the same actions without requiring precise particle targeting. Interfaces vary in seed-derived portal placement, color, symmetry, geometry and harmonic motion, while stable semantic names and units preserve usability. No NFT is denied a capability because of its seed.

The economic layers share owner authority, but only real included chain receipts are labeled onchain. Locally simulated results remain local. An edition can be collected without granting its code spending rights. A cartridge can execute in a sandbox without getting wallet authority. Selling the NFT can transfer account-owned assets and configuration rights, but cannot transfer a human author’s private encryption key or rewrite who authored a memory.

Shared visual links, portable world files, content-pinned cartridge manifests and transferable editions are the implemented foundations for reuse and network growth. Population counts, market depth, multiplayer and revenue are not fabricated.

The default IPSEITY donor also contains a syntactically truncated `tools/poc-pool.mjs`; this file is preserved as received and is not an application dependency. The authored-source syntax gate excludes retained `integrations/` trees and generated duplicate `dist/` output. Separate source audits describe the donors; an aggregate green test label is not applied to them.
