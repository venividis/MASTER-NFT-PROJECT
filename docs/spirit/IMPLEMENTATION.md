# Spirit Anima · 3.0.0

Separate Site and source fork of AWE Confluence 2.0.1. The published Confluence Site and all uploaded donor files are unchanged.

## Optical body

The full body uses a 14-sample absorption/emission volume with three-octave noise, five bounded absolute/inversion folds inspired by the original optical field, cosine interference colors, fine folded rims and bounded exposure. It is a new real-time optical treatment, not the original 88-step shader copied unchanged. A lower-resolution WebGL framebuffer holds the volume; 16,000 phone or 32,000 desktop particles render separately at display resolution in core and halo passes. Volume resolution adapts down when measured frame rate is low. WebGL failures move to a fresh Canvas with layered luminous veils and 4,000/8,000 points. The fallback has less optical detail and retains navigation, orbit and zoom.

## Matter becomes an instrument

A single opening parameter moves the volume and existing particle batch into a retained heart, a seeded superellipse contour and connecting veins. The renderer itself emits the visible membrane and dims the reading region. Transparent native semantic containers supply selectable text, labels, inputs and action hitboxes. Controls become visible during the unfold; closing reforms the body. This includes the inherited wallet connection and transaction review dialogs. Modal wallet consent remains modal, with a transparent backdrop and the animated body visible behind it.

The same chain-qualified identity digest drives body geometry, palette, fold parameters, border curves and control placement. A change of identity synchronizes both particle destinations and CSS coordinates. Every identity receives the same capability list; appearance cannot grant authority. Cryptographic identities can be distinct while human-readable names or visually similar forms can recur.

Phone and tall embedded layouts keep the body above an independently scrollable instrument. A shared effective viewport uses the visual viewport when a keyboard shrinks it. Reduced-motion preference is honored. Original mode clears animation-owned inline visibility styles before handing control to the preserved original renderer. The Compare link opens the earlier published Site with the current local preview seed.

## Retained functions and boundaries

Trade, locks, gifts, market, social, memory, publishing, work, commitments, laboratory, distribution, launch definitions, agent planning and isolated world cartridges retain their underlying state machines. The local economic instruments use fictional balances. Connected owner actions use the existing explicit simulation/review/signature adapters and require configured deployed contracts. Nothing in this UI fork deploys a public-chain economy, adds proof infrastructure or makes local balances real. Local state on the new Site is separate from Confluence; use the checked full archive export/import when transferring a local artifact between versions.

## Source map

- web/spirit/geometry.mjs — deterministic full body and shared instrument geometry.
- web/spirit/shaders.mjs — integrated volume, membrane and iridescent particles.
- web/spirit/field.js — render passes, adaptive resolution, recovery and viewport synchronization.
- web/spirit/surface.mjs — unfold visibility, native dialog integration and Original handoff.
- web/spirit/styles.css — transparent readable controls, seeded curves and responsive layouts.
- web/confluence/app.js — preserved capabilities with Spirit renderer and comparison entry.

No new runtime dependency was added. The existing lockfile marks Ganache's macOS-only fsevents entry optional so npm ci succeeds on Linux.
