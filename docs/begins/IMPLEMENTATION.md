# Anima Begins · 4.0.0

Third separate Site in the Confluence / Spirit Anima series. Earlier publications remain unchanged. This version makes the complete optical body become one central instrument, including its words and controls.

## What is original

The complete eight-fold field and 88-step ray-march functions from render/original.frag are retained byte-for-byte in web/begins/shaders.mjs. The original three wavelength-offset render samples are retained. A new projection gradually maps that field into the instrument footprint, with an iridescent organic boundary and a quiet interior for reading. Exposure is bounded to avoid unbounded white clipping. The source identity uses the existing chain-qualified sixteen-coordinate identity; an orthogonal sixteen-coordinate motion projection influences the camera, and a bounded memory contribution affects the optical projection. Higher mathematical coordinates describe the parameter space, not extra physical space.

## Formation

The default transformation is ten seconds. One persistent batch of 16,000 mobile / 32,000 desktop particles leaves the original body along curved paths and arrives at the interface. Thirty percent establish the organic perimeter; the remainder are allocated to measured text masks and native control outlines. Text is sampled from a temporary Canvas using the actual semantic element's font and measured position. Individual words arrive in reading order. Their particles fade as matching selectable DOM text becomes visible in place. Inputs, selects and buttons become usable when their content has arrived. There is no independent retained orb next to a popup. The optical material becomes the instrument's surrounding membrane.

Closing returns particles to the body in 3.6 seconds. Rapid route changes capture the current particle positions, including the final closing blend. Native input estimates do not restart formation. Complete formation skips the wait; reduced motion completes immediately. Original handoff clears all animation-owned visibility and inert state. Ready keyboard/viewport and identity reflows preserve native input focus and recollect destinations immediately.

Only visible text is rasterized for the current scroll position. Offscreen semantic text is revealed by completion and remains scrollable; scrolling during formation recollects the visible portion. Native controls, labels, transaction reviews, wallet prompts and validation retain their existing semantics. This is a creation animation over functioning instruments, not a screenshot pretending to be controls.

## Performance and recovery

The original optical field renders at a separately bounded resolution (85,000 target pixels on narrow screens, 180,000 otherwise), with adaptation when measured frame rate is low. Particles render at capped display resolution. The glyph masks are generated on layout changes rather than per animation frame. Completed semantic controls are not rewritten every frame. Canvas fallback uses luminous veils and half the particle population; it does not reproduce the exact original fractal shader. Link or allocation failure uses a fresh Canvas. A context loss that does not restore within 1.8 seconds moves to fallback and completes pending controls.
