## Source review changes during this build

The new gift/index/exchange deployment plan initially exposed a sealing cycle; explicit pre-seal router constructor dependencies removed that cycle while entry checks still require sealed matching modules. The commitment index now includes mandatory cell inventory plus per-module claims for both the root and its cell. Account instrument revision and nonce are part of exchange checks; session configuration also changes the instrument revision. The account now accepts external ERC-721/ERC-1155 collectibles without granting them execution authority; same-root-collection safe nesting remains disabled. Temporary exact allowances reset after execution.

The first new Library header and active laboratory tab inherited a submit-button width rule. Both were corrected and actual screens inspected. Per-role work/library and credit/option buttons now reflect known actor permissions rather than offering obviously unauthorized actions. Large grant input defaults use ungrouped decimal text so 1,000 AUR displays as an input-compatible 1000.

These are written source changes and observed local fixes, not certified contract fixes. Unknown external approvals/liabilities and arbitrary independent root-owner actions remain outside the cell's isolation guarantee. New live social event indexing and the wallet adapter remain absent.
