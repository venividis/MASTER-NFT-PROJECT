# i dont fucking believe it! — v1.6 / Operating Instruments

Open **preview.html**. Your approved organism is still the opening experience. Use **USE NFT ↗** beside Fold Space and Motion. The new **Library, Work, Commitments and Lab** tabs join the existing Trade, Launch, Lock, Give, Market and World.

**This is a working local rehearsal, with new uncompiled Solidity source—not a deployed financial product.** Every displayed balance, counterparty, collectible, receipt and experiment is local/fictional. No account, module or application chunk has been deployed by this release. The original optional testnet client remains separate and does not connect these instruments to a live protocol.

## Try the connected workflow

**Work:** act as You with artifact #1 and fund a commission for Guest. Change Act as to Guest, choose artifact #2, and accept. In Library, publish an edition, then return to Work to submit that edition. Change back to You to accept/pay. The worker receives the payment in their personal rehearsal balance; the reviewer is fixed even if the funding artifact later sells.

**Library:** adopt a published edition into your selected artifact. Publication/adoption grants no spending power. Open Test clock and advance seven days. Return to authorize one use, choosing caller, per-call/lifetime budget, call count and expiry. As that caller, review execution. Its receipt identifies the actual trigger. Revocation is immediate; ownership changes invalidate old grants without erasing the edition.

**Lab:** allocate a chosen amount of AUR and ETH from your selected artifact. Enable a module explicitly. Try strategy shares; a small two-asset basket; matched rights with a hypothetical loss; credit between You/#1 and Guest/#2; or a physically covered call. Use both personas and give each participating cell sufficient explicit funding. Existing positions and collateral are not free cell balance. Entry permissions must be renewed after ownership changes. There is no real token, price feed, yield or wallet transaction.

**Market:** Library can create a rehearsal collectible from an edition. Market → Operating shelves can offer it for a fixed ask with a bond date. A purchase moves the item; proceeds stay held until the bond ends. For the root NFT itself, inspect the complete contents before buying. Known gifts, jobs, libraries, grants, shelves and cell positions are included. If a counterparty changes a commitment while listed, the seller must refresh the manifest and the buyer must review it again.

**World:** inspect or discuss the exact publication, work payment or other typed action. Written text is not an execution record. Earlier authors do not change when the artifact is sold.

## Keep your earlier states

v1.6 uses a separate instrument-storage key for each original genesis. It does not overwrite your v1.5 save automatically. Export v1.5 instruments and explicitly Import them here to migrate the local data. Original organism history is separate and remains untouched. Imported old active listings need a fresh operating covenant before purchase. Browser storage is not permanent custody; Export to retain a copy. An unsigned checksum detects inconsistent edits, not a forged-but-consistent history or an authenticated wallet owner.

The future lens is read-only. Test clock really changes model time and can expire offers, mature bonds or enable refunds. Neither changes chain time. The original Seal Memory still discards text and salt; it is not a private notebook. Historical and Sovereign restrictions are not bypassed.

## What is deliberately not runnable

House leverage, Wager outcome books and Wake keeper seats have explicit architecture/invariant specifications but no executable mechanism or pretend unlock. Likewise: full independent PT/YT trading, root-NFT pawn/flash credit, the complete Bourse two-sided AMM, CCA, private agent execution, encrypted chat, omnichain movement and the new live-wallet adapter are not completed.

`npm run test:browser` — actual Chromium/Playwright checks.  
`node scripts/operating-package-check.mjs` — source tripwires and compiler input, not compilation.

`npm run compile` — requires the missing compiler; Cancun source/size gate.  
`npm run compile:local && npm run test:operating:contracts` — prepared Shanghai EVM harness, **not run here**.  
`npm run deploy` — refuses; no transaction.
