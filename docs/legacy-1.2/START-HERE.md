# i dont fucking believe it! — 1.2

Open **preview.html** in a browser. It contains the code, shaders, WebAssembly, and archived original. No installation or wallet is needed for the first view.

Start with **Evolve**. Watch the field settle, move the pointer, drag to orbit, and scroll to approach. **Fold space** changes the view through the fourth-coordinate slice, not the token's state. **Immerse** removes the instrument panels. Sound is opt-in.

**Spawn** adds an amber child; click it to enter its read-only form. **History** revisits older forms; **Return to present** restores the current head without rolling anything back. **Seal memory** retains only a salted digest and discards the text and salt. It cannot recover your thought.

**Ascend** is a confirmed, irreversible local rule change in preview. Connected testnet Ascension is a different, real transaction and can make the token unusable without valid proof infrastructure.

**ORIGINAL V1.0** opens the exact earlier preview; close it to return. **QUALITY** cycles Auto, Detail and Economy. Without WebGL, the optical field runs in WebAssembly at a lower computed frame rate, with interpolation between completed frames. The fallback is not the v1.1 wireframe.

**Export** preserves local history. **Portrait** saves current rendered pixels. Browser storage is convenient, not guaranteed permanent storage.

The **Connect** workflow is optional and testnet-only. It requires an actual compatible deployment and a wallet. No deployed contract address is fabricated. The adapter was tested against a mock provider, not a live wallet or blockchain. Solidity changes remain uncompiled in this environment.

For source usage: `npm run demo`. For dependency-free tests: `npm run validate:ui`. See `reports/VALIDATION.md` for evidence, not inferred success.
